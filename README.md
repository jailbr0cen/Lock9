# Lock9
<img width="320" height="568" alt="IMG_0009" src="https://github.com/user-attachments/assets/a07d0e2e-493c-42d7-a330-185c6ab51108" />

The iOS 9 slide to unlock, brought to rootless jailbreaks on iOS 15.

Lock9 is a rootless tweak that brings the iOS 9 slide to unlock and camera function to your lock screen. It features full customization in the Settings app. This tweak supports A8-A11 devices on all versions of iOS 15.

This tweak was made with components and code from NineUnlock by [minh-ton](https://github.com/minh-ton) and SixLS by [Skittyblock](https://github.com/Skittyblock).

Their repos can be found here: [NineUnlock](https://github.com/minh-ton/NineUnlock) [SixLS](https://github.com/Skittyblock/SixLS)

## Installation
Download the latest .deb from the [Releases](https://github.com/jailbr0cen/Lock9/releases) page, or use [theos](https://github.com/theos/theos) to compile and install.
